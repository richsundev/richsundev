## I'm a Senior AI/ML & LLM Engineer

I build and deploy **production-grade AI/ML and LLM systems** from research and experimentation to scalable inference and real-world applications.
My work combines **Python, PyTorch, Transformers, LLMs, RAG, AI agents, and cloud-native ML infrastructure** to deliver reliable, high-performance intelligent systems.

### 🔧 What I Do

* End-to-end **AI/ML and LLM system development**
* LLM application development with **OpenAI, Anthropic, Gemini, Llama, Mistral, and Hugging Face**
* **RAG pipelines**: document ingestion, chunking, embeddings, vector search, reranking, and retrieval optimization
* **AI agents** and tool-using LLM systems with multi-step reasoning and workflow orchestration
* Model **fine-tuning, evaluation, benchmarking, and optimization**
* ML/LLM inference optimization, **batching, caching, quantization, and GPU acceleration**
* Production ML infrastructure and **MLOps/LLMOps**
* Model serving with **vLLM, TensorRT-LLM, Ray Serve, FastAPI, and Kubernetes**
* Vector databases and search systems including **Pinecone, Weaviate, Milvus, Qdrant, and pgvector**
* Data and ML pipelines using **Airflow, Spark, Kafka, and distributed processing**
* Monitoring and observability for ML/LLM systems, including **latency, quality, drift, cost, and reliability**
* Cloud AI infrastructure across **AWS, GCP, and Azure**
* Building scalable AI APIs and backend services with **Python, FastAPI, and distributed systems**

Always interested in **AI/ML, LLM infrastructure, generative AI, agentic systems, MLOps, and open-source collaboration.**
